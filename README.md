# aman.aepx

After Effects extension by [@aman.aepx](https://www.instagram.com/aman.aepx/) · website: https://amanaepx.netlify.app

Download the latest version from **[Releases](../../releases/latest)**:

- `aman.aepx-2.12.0.zxp` — install with a ZXP installer
- `aman.aepx-2.12.0.zip` — install by hand (copy `com.jarvis.aeassistant` into `%APPDATA%\Adobe\CEP\extensions`)

Both files include a README with the install steps.

This is my first extension. If you find a bug, please DM **@aman.aepx** on Instagram with your After Effects version, your Windows version, what you did, and a screenshot.
